# Fiza Warranty Claim Guide

> A calm, factual, editorial landing page built with Next.js, TypeScript, and Tailwind CSS based on the **Blue Editorial** design system.

---

## Overview

A practical checklist for anyone preparing to file a warranty claim on a phone, TV, laptop, or home appliance. Decided on facts, in writing.

- **Author**: Fiza
- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS
- **Design System**: Blue Editorial (`#2563EB` blue accent, `#0D1117` secondary ink, Plus Jakarta Sans & JetBrains Mono)
- **Features**: Fully responsive, accessible, interactive checklist, plain-text download, and print support.

---

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
npm run build
npm run start
```

## Core Content & Structure
1. **Who This Is For**: Guidance for consumers with appliances or electronics under warranty seeking factual, written decisions.
2. **The Idea in One Line**: *"A warranty claim is decided on records. Keep yours, and ask for theirs in writing."*
3. **Key Numbers**: 15 steps, 4 records, 1 cardinal rule.
4. **15-Step Checklist**:
   - **Phase 01**: Before Anything Goes Wrong (Steps 1–4)
   - **Phase 02**: When The Fault Appears (Steps 5–7)
   - **Phase 03**: When A Technician Visits (Steps 8–10)
   - **Phase 04**: If The Claim Is Refused (Steps 11–15)
5. **Call to Action**: Downloadable checklist and quick sharing.
6. **Footer Note**: Free consumer disclaimer and attribution.
